Netflix Revenue Prediction

About the Project
This is our Machine Learning project based on Netflix revenue data. We applied different ML algorithms to analyse the data and predict revenue.

Algorithms Used
Supervised Learning:**
- Linear Regression
- KNN Regressor
- Decision Tree
- Random Forest

Unsupervised Learning:**
- Hierarchical Clustering
- K-Means Clustering

Tools Used
- Python
- Google Colab
- Pandas, NumPy
- Matplotlib
- Scikit-learn

Result
We compared the models using MAE and R² Score. Linear Regression gave the best result among the supervised algorithms in our analysis.
